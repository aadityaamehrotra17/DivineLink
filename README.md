# Divine Link

Full Stack Web Application for UoM Y1 team project (Built by Aadi, Taha, Joe, Abdel, Ian & Ahmed)

## About
Developed with a responsive front-end (Bootstrap CSS) and a PHP back-end, enabling users to engage with local places of worship, with secure password management (via salting/hashing), and integrated APIs for live prayer timings.

## Instructions

```bash
# Clone the repository
git clone https://github.com/aadityaamehrotra17/DivineLink.git

# Go into the project directory
cd DivineLink

# Start the PHP built-in development server (make sure PHP is installed)
php -S localhost:8000

# Open your browser and visit:
http://localhost:8000/home.php

# Alternatively, use XAMPP or something similar.
